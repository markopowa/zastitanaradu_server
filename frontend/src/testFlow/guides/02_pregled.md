# 02 — Tab Plan obaveza

Ranije „Pregled“. Skripta levo.

## Šta je ovo
- **Plan obaveza** = katalog tipova + status za firmu (BZR / ZOP).
- **Aktivne obaveze** = konkretni rokovi (Petar, PP aparat…) — drugi tab.
- Sivo = profil još ne pokriva. Boja = posao. Ručno NAP = ⋮ + razlog.

## Koraci
1. **C02_OVERVIEW_LIST** — Objasni plan.
2. **C02_OVERVIEW_MENU** — Ispravi.
3. **C02_NAP** — Dve vrste „nije primenljivo“.
4. **C02_OVERVIEW_BTNS** — Tri generatora (nisu checklista).
