# 05 — Tab Radna mesta i rizik

Skripta levo. Zeleno = prošao.

## Koraci
1. **E_ADD** — Dodaj radno mesto → Popuni.
2. **E_EDIT** — Izmeni radno mesto → Popuni.
3. **C05_RISK_TEXT** — Procena rizika (opasnosti / mere).
4. **C05_LZO** — LZO po mestu.
5. **C05_TRAINING_TYPE** — Vrsta obuke + blanko potvrda.
